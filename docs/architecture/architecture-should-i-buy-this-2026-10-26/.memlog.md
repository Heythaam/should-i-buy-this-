- (decision) AD-1 Pipeline stage contract - Binds all 8 feature branches - Prevents stages built independently assuming different input/output shapes or reaching into each other's internals - Rule: each stage is an async function with one typed Pydantic input and output, composed by one orchestrator module; stages never call each other directly
- (decision) AD-2 Canonical Product identity - Binds scraper, caching, alternatives, reddit - Prevents each stage inventing its own product-identity scheme, breaking caching/coalescing - Rule: a single canonicalize(url) function owned by the scraper stage is the only source of the Canonical Product id; every other stage and the cache key off this id
- (decision) AD-3 Data Source Port - Binds scraper stage - Prevents Tier 2 scraper logic and any future Tier 1 API from being wired incompatibly - Rule: product-fact retrieval goes through a ProductSource interface (fetch(url) -> ProductFacts or SourceFailure) with one implementation per tier; orchestrator calls the interface never a concrete scraper class. v1 ships only Tier 2 and Tier 3 implementations
- (decision) AD-4 Honest failure / no fabrication boundary - Binds scraper, reddit, llm-synthesis - Prevents any stage returning fabricated or partially-invented data disguised as success - Rule: every stage returns a populated typed result or an explicit typed failure/sentinel, never None-as-success; orchestrator maps a stage failure to the insufficient-data result (FR-3) rather than letting it propagate
- (decision) AD-5 Evidence Bundle is the only LLM input - Binds llm-synthesis - Prevents raw HTML, review text, or Reddit threads being piped directly into a prompt, bypassing the schema - Rule: llm-synthesis's only input type is the finalized EvidenceBundle Pydantic model; no access to raw scraper/reddit/alternatives internals
- (decision) AD-6 Confidence Score computed outside the LLM - Binds llm-synthesis, confidence-score - Prevents confidence logic being wired into the LLM call path - Rule: compute_confidence(evidence) -> float is a deterministic LLM-free function in its own module; llm-synthesis calls it after the LLM's Verdict draft and overwrites the confidence field - any LLM-produced confidence value is discarded
- (decision) AD-7 Verdict schema is the single frontend contract - Binds llm-synthesis, evidence-trail, confidence-score, ui - Prevents UI and synthesis stage drifting on field names/shapes - Rule: one Pydantic Verdict model is used for OpenAI structured-output enforcement, the FastAPI response model, and what the UI template renders - defined once, versioned, never duplicated. Must carry per-persona results plus a disagreement flag, resolving PRD Open Question 5's data contract even though the visual treatment is deferred
- (decision) AD-8 Caching and coalescing keyed on Canonical Product Id - Binds caching, all stages - Prevents concurrent requests for the same product re-running the pipeline independently, or caching on a different key than AD-2 - Rule: a single cache/lock module owns an asyncio.Lock registry keyed by Canonical Product Id; orchestrator checks cache, acquires lock, runs pipeline, writes cache, releases - no stage writes its own ad hoc cache
- (decision) AD-9 Graceful degradation on external dependency failure - Binds reddit, scraper - Prevents a rate-limited or unavailable external dependency blocking or crashing the whole request - Rule: Reddit and scraper calls are wrapped with a timeout plus single retry, then degrade to an explicit empty/partial result consumed by AD-4 - never raise unhandled out of the stage
- (decision) AD-10 Progress reporting via polling not streaming - Binds ui, orchestrator - Prevents ui assuming SSE/WebSocket while backend only exposes a simple status endpoint, or vice versa - Rule: orchestrator exposes GET /jobs/{job_id} returning a status enum plus the final Verdict when done; UI polls this endpoint on an interval (HTMX poll) - no SSE/WebSocket in v1. Resolves PRD Open Question 2
- (decision) Job queue (PRD/addendum Open Question): no external queue (no Celery/ARQ) in v1 - single orchestrator run via FastAPI BackgroundTasks/asyncio.create_task, job status tracked in the same SQLite store as the evidence cache.
